# Design Patterns in Python

Two small projects built for university, each demonstrating classic OOP design patterns.

---

## Ice Cream Shop

Simulates an ice cream shop using Singleton, Factory and Decorator.

**Patterns:** Singleton (one shop), Factory (creates ice cream by type), Decorator (adds toppings)

```bash
python ice_cream_shop.py
```

---

## Exam Day

Simulates a university exam using Singleton, Factory, Decorator and Strategy.

**Patterns:** Singleton (one university), Factory (assigns tasks by student type), Decorator (superpowers during exam), Strategy (how students arrive)

```bash
python exam_day.py
```
